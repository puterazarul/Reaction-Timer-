 Reaction Timer ⏱️

A simple web application designed to test and measure your reaction time in milliseconds.

 🚀 Live Demo
[Test your reaction time here](https://puterazarul.github.io/Reaction-Timer-/)

 ✨ Features
- **Speed Test**: Measures how quickly you can react to screen prompts.
- **Instant Results**: Displays your precise reaction speed in milliseconds.
- **Responsive Design**: Works on both desktop and mobile browsers.

🛠️ Tech Stack
- **HTML5** — Page structure
- **CSS3** — Styling and visual cues
- **JavaScript** — Timing logic and DOM manipulation
